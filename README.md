# KawanAjar

Prototipe ruang kerja guru sekolah dasar untuk menyimpan materi, membuat bank soal, menyusun ulangan dan UTS/SAS, serta mengelola kelas dan siswa. Antarmuka menggunakan Blade, Bootstrap 5, Bootstrap Icons, dan gaya SB Admin.

## Menjalankan aplikasi

1. Atur koneksi database di `.env`.
2. Jalankan migrasi: `php artisan migrate`
3. Isi contoh data untuk demo lokal: `php artisan db:seed`
4. Buat tautan lampiran: `php artisan storage:link`
5. Jalankan aplikasi: `php artisan serve`

Akun contoh lokal: `demo@kawanajar.id` dengan kata sandi `Kawanajar#Demo2026`. Ganti atau hapus akun contoh sebelum aplikasi digunakan di lingkungan bersama atau produksi. Data contoh memakai nama dan NIS fiktif.

## Pembuatan soal dengan Mistral

Fitur soal AI tidak aktif sampai `MISTRAL_API_KEY` di `.env` diganti dengan kunci API yang valid. Model dan endpoint dapat diatur melalui `MISTRAL_MODEL` dan `MISTRAL_API_URL`. Tanpa kunci API, guru tetap dapat membuat soal secara manual.

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
